# Source observations for the people directory

`shadow-source-observations <snapshot-or-capture-manifest> <new-output-directory> [--resume]` produces typed people, credit and performance observations for `source_sample` rows. It observes the retained artist and catalog context, uses the same credit/alias extractors and actor construction as full matching, and preserves all six original fields. An optional pinned Luna cache contributes its original extraction and provenance without an API call.

This command does not build the global people index, retrieve candidates, score pairs or construct canonical identity decisions. Its people method starts with `shadow-people-source-observations-v1`; the input identity starts with `source-observations-inline/`; `population.processingScope` is `source_actor_observations`. The typed people proposal declares `matchingState: not_run` and `automaticAcceptanceAuthorized: false`. Comparison and coverage arrays are absent, so this output cannot be presented as a complete empty candidate search. Full `shadow-inline` matching remains unchanged.

Only `RELISTEN_SHADOW_LUNA_CREDITS` and `RELISTEN_SHADOW_LUNA_INPUT_SHA256` are accepted optional evidence inputs for this command. Identity model/candidate, provider, geography and composition environment references are rejected. Capture receipts, extractor methods and the processing scope remain part of resume verification. Changed scope, inputs or methods require a new output directory; an interrupted full-matching run cannot be relabeled or resumed as source observations.

The source-only scope excludes file outcomes. Existing source/show assignments and performance home observations retain their UUIDs; existing playable-file links continue to use the directory's original `sourceRun` namespace. This command does not publish a directory or accept identities. Before a new people generation is published, independently verify the entire cached cohort and its retained model credit count, then use `refresh-sources` to preserve exact unchanged credit witnesses and invalidate only changed context links. The earlier frozen comparison cohort and native overlay keep their original producer evidence.

Approved identity vocabulary.

Approved — 29 Oct 2026

Every Relisten catalog resource reference uses its target’s typed string. The table names the actual entities; it does not change imported entities into normalized ones.

U26: exact existing UUID bits in 26 lowercase Crockford characters. S8: existing normalized suffix. Prefixes can contain underscores; split at the last underscore.

# Archive collections design

Use the current [Relisten collections design](2026-10-17-relisten-collections.md) for collection identity, selected-recording and artist-wide membership, Aadam Jacobs integration, and Jerry Garcia performer assignment. The [execution plan](../plans/active/2026-10-17-archive-collections/README.md) records the next work separately.

The current model preserves one canonical recording while allowing several collections to include it. Aadam membership selects particular recordings; a Jerry collection can include entire reviewed performing projects. Collection membership does not determine the performer or transfer ingestion ownership.

The implemented [Taper’s Section contracts](../plans/active/2026-10-16-taperssection-intake/contracts.md) remain authoritative for current intake. Collections, existing-artist publication, and Aadam support are planned extensions. This page redirects to the current design; it defines no additional migration or API contract.
